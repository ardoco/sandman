## Goal

The walking skeleton runs in CI in strict `replay` mode from committed cassettes, and a determinism test shows that a replayed run produces the same canonical KG export as the recorded one.

## Scope

1. **Cassette directories.** Make the host directory mounted at `/llm-records` configurable in compose (default `../data/llm-records`); CI and `make e2e` mount `tests/cassettes` and set `SANDMAN_EXPERIMENT=walking-skeleton`, `SANDMAN_LLM_MODE=replay`.
2. **`Run.replayMode`.** Agents record the actual mode instead of the hard-coded `live` default (source per open question 2), in both libraries' run recorders.
3. **`ORDER BY` audit.** Every KG read whose result enters a prompt or the order of LLM calls sorts on a stable key (today: `services/extraction-agent` enrichment from T1.5). Add a short rule to the library docstring of `KgClient.read`.
4. **Canonical KG export** `scripts/kg_canonical_export.py` (Bolt, read transaction, one project): nodes reachable from the project plus its `Run`s, as JCS-sorted JSON; drops properties with random or time-based values (`Run.id`, every `runId`, `a2aTaskId`, `workflowId`, `*At`, `agentVersion`); relationships as `(type, source, target)`, with `Run` endpoints replaced by their canonical content. The strip list is a constant in the module and every entry has a one-line reason.
5. **Determinism test** `tests/e2e/test_replay_determinism.py` (`SANDMAN_E2E=1`, fresh stack, fixed project id `replay-mini`): ingest `tests/e2e/fixtures/mini`, wait for the workflow, export, compare with the golden file `tests/cassettes/walking-skeleton/kg-canonical.json`; assert `llm-replay` `/v1/status` reports `misses == 0`.
6. **Recording procedure.** `make record-cassettes` (profile `stubs`, `chat-local` served by the remote Ollama endpoint, `SANDMAN_LLM_MODE=record`, fresh stack) records `tests/cassettes/walking-skeleton/cassette.jsonl` and regenerates the golden export. Changing a prompt requires re-recording (makes prompt changes visible in review).
7. **Experiment manifest** `experiments/<name>/experiment.yaml` written by `scripts/experiment_manifest.py`: Git commit (+ dirty flag), image digests, sha256 of every file under `config/` and of `deploy/gateway/config.json`, routes from `config/llm/models.yaml`, project snapshot hashes, LLM mode, experiment name, seeds.
8. **Cassette hygiene check** (pytest under `tests/`): every committed cassette validates against `CassetteEntry` in `contracts/common.schema.json` and contains no bearer tokens or `sk-` keys.

Out: LangChain4j/Java callers (M2, T2.2), embeddings cassettes beyond what T1.5 records, nightly live canary (Stage 3 §3.2 item 3, open question 4), `experiments/PROTOCOL.md` (T2.3), changes to the cassette format or key.

## Acceptance criteria

- CI `e2e` job runs the walking skeleton and the determinism test in `replay` mode with no provider keys and no remote Ollama; a missing cassette entry fails the job (strict replay).
- Two consecutive replay runs on fresh stacks produce byte-identical canonical exports, equal to the golden file.
- Every `Run` written in the replay run has `replayMode = replay`; in `record` mode `record`.
- Changing one character in `prompts/summary.txt` (T1.5) makes the determinism test fail (`misses > 0`; the llm-replay log line names the key).
- `scripts/experiment_manifest.py` output for a running stack contains every field of Stage 1 §11.6; unit test on a fixture directory.
- e2e job stays within A3-4 (< 15 min incl. image builds).

## Test plan

Unit tests for the export (strip list, `Run` endpoint canonicalization, sort order) against a small graph in Testcontainers Memgraph; unit test for the manifest script; cassette hygiene test in the normal `pytest` run; the e2e determinism test in the CI `e2e` job. No test calls a live model; only `make record-cassettes` does, by hand.

## Constraints

Python 3.13, uv only; scripts use the workspace dependencies (`neo4j`, `rfc8785`, `pyyaml`), no new ones without asking. Do not change `contracts/` or the llm-replay cassette key. Keep a handoff note `.work/T1.6.md` (CLAUDE.local.md).
