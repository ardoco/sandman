# T4.5 Strategy `graphrag`

Milestone M4 · Effort M · Depends on: T4.1, T4.1b, T4.3 · Blocks: T4.7

Status: done (2026-10-17).

## Context

Strategy `graphrag` answers questions that the schema cannot express as one Cypher query. It finds elements by meaning and then reads their neighbourhood. Read first:
- `adr/0018-query-strategies.md`, `docs/tasks/T4.1-nl-to-cypher-strategy.md`, `docs/tasks/T4.1b-element-embeddings.md`, `docs/tasks/T4.3-answer-synthesis-citations.md`
- Code: `services/query-service/src/sandman_query/` (`nl.py`, `synthesis.py`, `scope.py`, `reader.py`).

## Goal

A question is embedded through the gateway. The nearest elements of the project are the seeds. Bounded Cypher adds their neighbours. The rows and an evidence list go to the T4.3 synthesis.

## Scope

1. **Config.** `config/query/strategies.yaml`, key `graphrag`: `enabled` [false], `topK` [5], `overFetch` [20], `maxNeighbours` [5], `dimension` [768]. The schema `contracts/config/query-strategies.schema.json` allows these keys only.
2. **Embedding.** Embed the question with `ModelSelector.embed_model(llmPolicy)`. A local-only project uses `embed-local`. Cut the vector to `dimension` and normalise it, as the extraction-agent does.
3. **Search.** One fixed template calls `vector_search.search('element_embedding', k, $vector)`. Set `k = topK * overFetch` [100]. The index has no property filter. Filter `projectId` after the search. Run `check_scope` on the hits. A foreign hit gives 422.
4. **Expansion.** For each seed, read the current-version data and the neighbours through `Runner.run`. The guard, the memory limit and the scope check apply. Use the relations `CONTAINS`, `DEPENDS_ON`, `PROVIDES`, `REQUIRES` and the active trace links. Keep `maxNeighbours` [5] per seed. Cut `text` to 500 characters.
5. **Response.** Fields: `strategy: graphrag`, `rows` (`key`, `name`, `kind`, `text`, `relation`, `from`), `evidence` (seeds with `score`, neighbours with `path`), `warnings`, `model`, `resolvedModel`, and `answer` with `citations` when T4.3 accepts the answer. No `cypher`.
6. **Errors.** No embeddings in the project: 409. No LLM access, LLM failure, budget exhausted or graph error: 503 without internal detail. `mode=cypher-only` and `execute=false` embed nothing and run nothing. They return a warning.
7. **Bundled fixes.**
   - F-5: a graph error in `NlService.policy` gives 503.
   - F-6: the "answer dropped" warning does not repeat ids from the LLM.
   - `schema_text` skips properties with `internal: true`.
8. **Registration.** `NlService` registers `graphrag` and `explore` (T4.6).

Out: re-ranking, hybrid keyword search, check of the stored `embeddingModel` against the query model [not verified; add when models change], a pre-filtered index.

## Acceptance criteria

- Fake-embedding tests: rows and evidence, citations from evidence, route `embed-local` or `embed-default`, 409 without embeddings, empty result without hits, embedding failure gives 503 without leak, foreign hit gives 422.
- Memgraph test (Testcontainers): search, expansion and isolation. No data of the other project appears in the response.
- The graphrag cases of the T4.4 security suite run and pass.
- Tests for F-5, F-6 and `schema_text`. A test shows that `explore` answers and does not give 501.
- Responses validate against `contracts/openapi/query-service.yaml` (new 409 response).
- `scripts/validate_contracts.py`, `ruff check`, `ruff format --check` and `uv run pytest services/query-service` pass.

## Constraints

Existing dependencies only. All expansion Cypher goes through `Runner.run`. Keep a handoff note `.work/T4.5-impl.md`.
