## Acceptance criteria

- Tests with a zip bomb, an entry-count bomb, a hardlink, a device entry, `..\x`, `C:\x` and an XXE/billion-laughs XMI: each rejected with a clear error and bounded memory.
- A fresh stack records `SchemaVersion`; a second `kg-migrate` run changes nothing.
- A forced fallback in a test gateway marks `Run.mixedModels`; `experiments` routes have no fallbacks (config test).
- The custom-provider check passes against a stub OpenAI-compatible server.
- `grep` finds no floating `latest` tags and no `FROM` without digest in the repository; Renovate config validates.
- `make e2e` and CI stay green; e2e < 15 min.

## Deviations

- LiSSA `ARG LISSA_COMMIT` is deferred to T2.2, because nothing fetches LiSSA yet.
- The apt package `curl` is unpinned in the Java Dockerfiles.
- The testcontainers images use tags only.
- The extraction agent holds uploaded archives in memory. The caps `SANDMAN_MAX_ARCHIVE_BYTES` and the new `SANDMAN_MAX_ENTRY_BYTES` bound the size.
- The agent messageId dedupe is in memory (1024 entries). A restart clears it. The orchestrator `_poll` recovers.
- `kg-migrate` is the first applier of `init.cypher`. The owners keep their idempotent `init_schema`.
- No Java code parses XMI, so no DTD change is needed.
- The OpenRouter pin uses the `openrouterProviders` map in `config/llm/models.yaml`. `llm-replay` reads it. `pyyaml` is added to `llm-replay` (approved by the user).
- Orchestrator retries reuse the messageId of an unacknowledged attempt.
- An empty archive without a manifest returns 400.
