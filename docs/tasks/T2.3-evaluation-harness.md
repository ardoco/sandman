## Goal

A user can export current trace links in the formats of the ArDoCo and LiSSA benchmarks. A user can compare two approaches (or one approach and a published value) on one project with the statistics of the protocol. The protocol is a committed, hashed file, so changes after data collection are visible.

## Scope

1. **`experiments/PROTOCOL.md`**: the pre-registered protocol, version 1. It fixes metrics, statistics (paired bootstrap, McNemar, effect sizes, Holm, Wilcoxon only with at least 6 projects), reproduction rules, the variance pilot rule, the contamination probe, the NL-to-Cypher rules, and the deviation log.
2. **Python package `sandman_cli.evaluation`** (standard library only):
   - `stats.py`: `prf` (precision, recall, F-beta), `paired_bootstrap` (10 000 resamples, percentile 95 % CI of metric differences, seeded), `mcnemar_exact`, `cohens_g`, `odds_ratio`, `cliffs_delta`, `holm`, `wilcoxon_exact` (raises `ValueError` below 6 pairs), `runs_needed` (variance pilot), `contamination_verdict`.
   - `formats.py`: the gold readers and writers for `ardoco-sad-sam`, `ardoco-sad-code`, `lissa`; `rows_to_format` maps KG link rows to the benchmark format.
   - `compare.py`: `compare` builds the per-project report (metrics with CIs, McNemar, effect sizes) from link sets and gold.
3. **CLI**:
   - `sandman export tracelinks --format ardoco-sad-sam|ardoco-sad-code|lissa [--approach ID] [--code-root PREFIX]`. The CLI reads the links through `POST /v1/query/cypher` (viewer role, paginated) and writes the benchmark format. The mapping runs in the client (open question 1).
   - `sandman eval compare --gold FILE --format F --a FILE [--b FILE] [--published F1] [--seed N]`: JSON report on stdout.
4. **Experiment manifest**: `scripts/experiment_manifest.py` records the SHA-256 of `experiments/PROTOCOL.md`, its version, and optional gold standard files (`--gold PATH`, repeated) in the new section `evaluation`. Existing fields stay.
5. **Contract**: none in this task (open question 1, open question 4).

Out: query-service server-side `format` values (T4.1 owns `services/query-service`; the contract enum follows with it); a manifest JSON Schema; gold standard vendoring; running experiments (T2.4); NL-to-Cypher evaluation code (T3.3 or T4.x).

## Acceptance criteria

- Gold standard files of all five benchmark projects round-trip: read, write, read gives the same set.
- `rows_to_format` produces, for a fixture KG row set, exactly the rows of the gold-standard layout (header, 1-based sentence, sorted).
- `paired_bootstrap` with a fixed seed is deterministic. On a hand-computed case, the CI contains the point estimate. Identical systems give a CI of `[0, 0]`.
- `mcnemar_exact` equals reference values (b = 8, c = 2 gives p = 0.109375). `holm` equals the textbook adjusted values and is monotone. `wilcoxon_exact` refuses fewer than 6 pairs and gives p = 0.03125 for 6 same-sign pairs.
- `sandman eval compare` and `sandman export` run end to end against fixtures (`httpx.MockTransport` for the export).
- `experiments/PROTOCOL.md` is hashed in the manifest; a unit test fails if the manifest section is missing.
- `ruff`, `mypy --strict` and `pytest tools/cli scripts` pass.
