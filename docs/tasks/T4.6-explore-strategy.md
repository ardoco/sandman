## Goal

A question is answered by a loop of at most [8] steps. In each step the LLM picks one tool from a small fixed set. The service runs the tool through the guarded reader, scoped to the project. The result (rows, evidence, steps) goes to the existing synthesis of T4.3. The strategy is off by default.

## Scope

1. **Tools.** Each tool is one fixed Cypher template. The model supplies only parameter values. The model never writes Cypher.

   | Tool | Arguments | Returns |
   |---|---|---|
   | `list_types` | none | element kinds with counts |
   | `find_elements` | `query`, `kind?` | current elements whose name, qualified name or text contains `query` |
   | `get_element` | `key` | one element with its text |
   | `neighbors` | `key`, `direction?` (`out`, `in`, `both`) | elements linked by `CONTAINS`, `DEPENDS_ON`, `PROVIDES`, `REQUIRES` |
   | `trace_links` | `key`, `direction?`, `minConfidence?` | partners of active, non-rejected trace links |
   | `finish` | `keys` | ends the loop; the keys are the answer |

   The model answers with structured output (flat schema, `tool` plus the arguments above). A key that no earlier tool result returned is dropped at `finish`.
2. **Scope.** Every template goes through `Runner.run` (parse-tree guard, `$projectId` anchor, read transaction, memory limit, timeout, result post-check). The runner binds `projectId`. The model cannot name a project: arguments other than the listed ones are dropped. Every template returns the element `projectId`; a row of another project aborts the request with 422.
3. **Budgets** (keys under `explore` in `config/query/strategies.yaml`, all optional): `maxSteps` [8], `maxTokens` [20000] (usage of all calls; estimate when the gateway reports none), `maxRows` [100] (rows read from the graph in total), `maxRowsPerTool` [20], `maxSeconds` [60] (wall time, also bounds each tool query). An invalid tool call counts as a step. When a budget is used up, the loop stops, the result has no rows and a warning names the budget.
4. **Untrusted data.** Tool results go to the model as `<tool_result>` blocks. Strings are cut to [300] characters. `<` and `>` are escaped (`<`), so element text cannot close the block. The system prompt says the block is data. The question stays the only user message that is not a tool result.
5. **Response.** `strategy: explore`, `columns` (`key`, `kind`, `name`), `rows` (the chosen elements), `evidence` (`key`, `path`), `steps` (`tool`, `input`, `rows`, `error`), `attempts: []`, `warnings`, `model`, `resolvedModel`. `answer`/`citations` come from the T4.3 synthesis, which may cite only row values or evidence keys. `mode=cypher-only` and `execute=false` run nothing (no LLM call; a warning says so). No LLM configured: 422. LLM errors: 503 without detail.
6. **Registration.** `sandman_query.strategies.explore.register(nl)` adds `explore` to `NlService.strategies`. The strategy is enabled in `strategies.yaml` (`explore.enabled`); otherwise 501.

Out: free-form Cypher, vector search in `find_elements` (needs T4.1b/T4.5; add as an `embedding` mode later), parallel tool calls, fallback to another strategy, answer streaming.

## Acceptance criteria

- Scripted-LLM tests: loop with `find_elements` then `finish`, rows, evidence, steps, synthesis with citation; invalid and unknown tools never reach the reader; keys not seen are dropped; each budget stops the loop (steps, tokens, rows, wall time); `cypher-only` runs nothing; LLM failure gives 503 without detail; disabled gives 501.
- Hostile arguments: `projectId` or `cypher` in the model output has no effect; injection text in `query` and `key` is bound as parameter and is not part of the query text; every query binds the caller's project.
- Untrusted output: element names with `</tool_result>` cannot close the block.
- Security suite (`tests/security/test_query_path.py`): the `explore` cases run (no longer skipped) with guard on and off; forged foreign rows (node, relationship, list, map, path, Project) give 422 and no marker.
- Memgraph test (Testcontainers): two projects, foreign marker in project `beta`; a script that asks for `beta` keys and the marker gets no foreign data in any tool result, request or response; foreign keys are dropped at `finish`.
- `uv run ruff check`, `ruff format --check`, `uv run pytest services/query-service` green.

## Findings and open points
